# Football Puzzle - простой MVP GDD

Версия: 0.1  
Дата: 2026-05-30  
Статус: зафиксированные решения для MVP

## 1. Концепция

**Football Puzzle** - пошаговая футбольная головоломка для веб-платформ. Игрок управляет футболистом на клеточном поле и должен довести его до ворот, двигаясь по заранее нарисованным линиям маршрута и избегая защитников.

Игра должна ощущаться как казуальная match-3/puzzle игра: понятная, яркая, с короткими уровнями, наградами, постепенным усложнением, скинами и бустерами.

## 2. Цель Уровня

Цель каждого уровня - дойти футболистом до ворот.

Сам удар по воротам не является отдельной игровой механикой. Когда игрок достигает ворот, можно показать красивую анимацию забитого гола и затем экран победы.

## 3. Поле И Движение Игрока

- Поле явно клеточное.
- Игрок ходит только по синей линии маршрута.
- Один ход - это перемещение на одну соседнюю клетку.
- Игрок может двигаться по синей линии в любом направлении.
- Синие линии всегда двусторонние.
- Игрок не может наступить на клетку, где прямо сейчас стоит враг.
- Обычного действия "подождать на месте" нет.
- Пропуск хода может быть только бустером.

Если игроку нужно изменить тайминг, уровень должен давать это через маршрут: петлю, обход, развилку или дополнительный путь.

## 4. Враги

Враги - защитники, которые ходят по своим красным линиям.

Базовые правила:

- Обычный враг ходит на 1 клетку за ход.
- После хода игрока все враги двигаются.
- В MVP враги двигаются логически одновременно.
- Если враг после движения оказался на клетке игрока, игрок проигрывает.
- Враг ловит игрока только на своей клетке.
- Зон контроля вокруг врагов в MVP нет.

Маршруты:

- Если маршрут врага линейный, враг ходит туда-сюда.
- Если маршрут замкнутый, враг ходит по кругу.
- В MVP у врагов нет пауз на маршруте.
- В будущем можно добавить другие типы врагов, но они должны сильно отличаться визуально, чтобы игрок понял, что у них другие правила.

## 5. Поражение

Игрок проигрывает, если враг приходит на его клетку.

При поражении:

- показывается анимация перехвата;
- внимание игрока привлекается к кнопке бустера "Отмена хода";
- если бустер есть, игрок может откатиться назад;
- если бустера нет, можно предложить получить его за rewarded-рекламу;
- если лимит рекламы исчерпан, открывается окно покупки.

Рестарт уровня бесплатный и мгновенный.

Незавершенная попытка уровня не сохраняется. Сохраняется только прогресс между уровнями.

## 6. Победа И Звезды

Уровень всегда можно пройти хотя бы на 1 звезду.

Пороги звезд задаются вручную для каждого уровня:

- 3 звезды - пройти за малое количество ходов;
- 2 звезды - пройти за среднее количество ходов;
- 1 звезда - любое успешное прохождение.

На экране уровня нужно показывать количество ходов. Также можно привязать UI ходов к звездам, например показывать пороги для 3 и 2 звезд.

После победы показываем:

- полученные звезды;
- количество ходов;
- награду;
- кнопку следующего уровня;
- кнопку переиграть;
- кнопку выбора уровней.

## 7. Бустеры

Бустеры доступны на любом уровне.

Бустеры MVP:

1. **Отмена хода**
   - Возвращает игру в состояние до последнего хода игрока.
   - Откатывает счетчик ходов.
   - Может использоваться после поражения.

2. **Пропуск хода**
   - Позволяет игроку пропустить свой ход.
   - Враги при этом делают свой ход.
   - Предварительное решение: не увеличивает счетчик ходов.

3. **Убрать врага**
   - Убирает выбранного врага с поля на текущую попытку.
   - Предварительное решение: не считается ходом.

Использование бустеров не запрещает получить 3 звезды, если игрок уложился в нужное количество ходов.

Бустеры можно получать:

- как награду;
- за ежедневный бонус;
- за rewarded-рекламу;
- через донат.

Основной способ получения большого количества бустеров - донат.

## 8. Прогрессия И Лиги

Уровни объединены в лиги.

Звезды не тратятся. Они являются показателем прогресса и нужны для открытия новых лиг.

Пример структуры:

- Дворовая лига;
- Городская лига;
- Профессиональная лига.

Для MVP достаточно 2-3 лиг.

Количество уровней в лигах может быть разным. Внутри открытой лиги не все уровни обязаны открываться строго по порядку. Игрок должен иметь возможность выбрать другой доступный уровень, если застрял.

Часть уровней внутри лиги может быть закрыта и открываться за звезды. Последний уровень лиги может быть сложнее остальных, но его не нужно явно выделять как boss level.

Можно добавлять тематические лиги в будущем: новогоднюю, космическую, пляжную и другие.

## 9. Награды И Экономика

В игре есть:

- звезды;
- soft currency;
- hard currency;
- бустеры;
- скины.

Звезды:

- выдаются за прохождение уровней;
- не тратятся;
- открывают новые лиги.

Soft currency:

- футбольная мягкая валюта;
- используется в основном для покупки скинов;
- точное название нужно выбрать позже.

Hard currency:

- премиальная валюта;
- основной источник - донат;
- немного может выдаваться бесплатно, но только на мелкие покупки.

Возможные названия:

- soft currency: футбаксы, кредиты, трансферные деньги;
- hard currency: золотые бутсы.

У каждого уровня есть пул монет. Игрок получает награду только за новый прогресс:

- прошел на 1 звезду - получил первую часть пула;
- улучшил до 2 звезд - получил разницу;
- улучшил до 3 звезд - получил оставшуюся часть.

Полностью забранный уровень не должен быть бесконечным источником валюты.

## 10. Реклама И Донат В MVP

Первичная платформа для теста - **Яндекс Игры**.

Для интеграции рекламы, сохранений и платформенных функций планируется использовать **PluginYourGames 2.0**.

Поверх PluginYourGames нужна собственная обертка, чтобы игровой код не зависел напрямую от конкретной платформы. Скрипты игры обращаются к нашему сервису, а сервис уже вызывает рекламу, сохранения, покупки и другие платформенные функции.

Для MVP полноценный магазин не нужен.

Rewarded-реклама:

- получить бустер после поражения;
- получить бустеры в ограниченном дневном объеме.

Rewarded-реклама не должна выдавать hard currency.

Interstitial-реклама:

- не при выходе из уровня;
- можно показывать после нескольких проигрышей;
- можно показывать после прохождения нескольких уровней;
- не нужно показывать сразу и слишком часто.

Перед interstitial должна быть надпись с обратным отсчетом, например: "Реклама через 3... 2... 1...".

В MVP не нужны:

- полноценный магазин;
- remove ads;
- стартовый платный набор.

## 11. Скины И Кастомизация

В MVP один базовый персонаж.

Кастомизация MVP:

- футболка;
- шорты;
- носки;
- бутсы.

Выбранная одежда должна быть видна на персонаже во время уровня.

Игрок покупает конкретный предмет, не случайный сундук.

Можно продавать как отдельные предметы, так и комплекты. Комплект просто быстро надевает несколько предметов сразу.

Редкость предметов не нужна в MVP.

Скины в MVP должны быть косметикой и не влиять на геймплей. В будущем можно добавить редкие комплекты, которые дают небольшой бонус, например 1 бустер в день, но это не задача MVP.

Враги могут менять внешний вид в зависимости от лиги.

## 12. Визуальный Стиль

Ориентир - яркий casual/match-3 стиль:

- крупные читаемые персонажи;
- толстый контур;
- простые формы;
- яркие цвета;
- дружелюбное настроение;
- сочный UI.

Персонаж должен быть похож по настроению на референс: рыжие волосы, голубая футболка, белые шорты, темные бутсы, но дизайн должен быть оригинальным и менее квадратным.

Карта уровня:

- вид сверху;
- ортографическая камера;
- мягкая, но читаемая сетка;
- футбольный газон;
- светящиеся маршруты.

Персонажи:

- финальные анимации планируются через Spine;
- персонажи могут быть показаны как billboard/2D-фигуры на top-down карте;
- нужно тестировать, как лучше совместить вид поля сверху и персонажей в более боковом/3/4 виде.

Линии:

- синяя линия игрока светящаяся;
- красная линия врага светящаяся;
- у красной линии можно использовать бегущие стрелки;
- у синей линии лучше осторожно использовать стрелки, потому что движение игрока двустороннее.

Следующая позиция врага показывается ghost-образом всегда.

## 13. Камера И Управление

Управление нужно тестировать.

Возможные варианты:

- клик/тап по соседней доступной клетке;
- свайп в сторону;
- клавиши на desktop.

Подсветку доступных ходов тоже нужно тестировать.

Камера:

- должна работать с top-down картой;
- если уровень не помещается на экран, камера может следовать за игроком;
- нужен ручной zoom;
- нужно тестировать, должен ли игрок всегда видеть весь уровень или только часть поля.

Враги визуально двигаются все сразу.

На экране уровня нужны:

- кнопка меню/паузы;
- бустеры;
- счетчик ходов;
- возможно, отображение порогов звезд.

В паузе:

- рестарт;
- выход из уровня;
- настройки, если будут нужны.

## 14. Помощь Игроку

Если игрок несколько раз проигрывает на одном уровне, нужна мягкая помощь.

Возможная лестница помощи:

1. После нескольких поражений привлечь внимание к бустерам.
2. Предложить rewarded-рекламу за нужный бустер.
3. Предложить подсказку.
4. Если в лиге есть другие доступные уровни, предложить попробовать другой уровень.

Подсказку нужно продумать отдельно. Самый безопасный вариант для MVP - показывать один следующий безопасный ход, а не полное решение.

## 15. Будущие Механики Не Для MVP

Идеи на будущее:

- другие типы врагов;
- движущиеся препятствия, которые блокируют путь;
- специальные клетки;
- несколько футболистов;
- передача мяча между футболистами;
- мяч как отдельное состояние `ballOwner`;
- механики, временно блокирующие врагов;
- тематические лиги;
- редкость скинов;
- легендарные комплекты с небольшими бонусами.

## 16. Открытые Вопросы

Нужно будет решить во время прототипирования:

- точные названия soft и hard currency;
- сколько уровней будет в каждой MVP-лиге;
- точные пороги открытия лиг;
- точную формулу наград из пула уровня;
- как именно выглядит экран победы;
- какое управление лучше работает на desktop и mobile;
- насколько явно подсвечивать доступные клетки;
- как камера должна вести себя на больших уровнях;
- как именно выглядит подсказка после серии поражений;
- как совместить top-down поле и Spine-персонажей.

## 17. Критерии Успешного MVP

MVP можно считать успешным, если:

- игрок понимает базовые правила за первые уровни;
- поражение всегда понятно;
- маршруты врагов читаются заранее;
- игрок видит следующую позицию врага;
- уровни не слишком простые и не слишком сложные;
- звезды мотивируют переигрывать;
- бустеры помогают пройти сложные места;
- скины дают приятную долгосрочную цель;
- реклама не раздражает слишком рано;
- игра технически готова к тесту на Яндекс Играх.
